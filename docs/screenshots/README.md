# Скриншоты для сдачи

Каталог намеренно не содержит вымышленных кадров. После ручного запуска сохраните сюда изображения с такими именами:

1. `01-start-menu.png` — `/start` и главное меню.
2. `02-five-ideas.png` — пять идей постов.
3. `03-brief-and-post.png` — финальный шаг брифа и готовый текст.
4. `04-image-preview.png` — изображение и предпросмотр.
5. `05-publish-confirmation.png` — дополнительное подтверждение.
6. `06-channel-result.png` — материал в тестовом канале.
7. `07-tests-passed.png` — терминал с полным результатом pytest.

## Правила

- не показывать `.env`, токены, API-ключи и личные переписки;
- использовать тестовый канал;
- при необходимости скрыть фамилии, username и аватары;
- не выдавать мок-заглушку за результат реальной генерации;
- обновить `test_report.md` после ручной проверки.
