## Что считать завершением ручной проверки

После подключения Telegram необходимо пройти сценарии 1, 6, 9–12 и сохранить кадры. Для реального AI-режима дополнительно проверить сценарии 3, 4, 6 и 14. После этого заменить статусы в таблице на фактические и указать дату, аккаунт тестового канала без секретных данных и обнаруженные ограничения.

## Выполненный ручной маршрут

`/start` → пять идей → бриф из шести шагов → мок-текст → мок-изображение → предпросмотр → отдельное подтверждение → публикация в частный тестовый канал. Сохранены кадры `01`–`06` в `docs/screenshots/`. Реальный OpenAI API не использовался, расходы отсутствуют. Сценарии отказа от публикации и длинного текста остаются подтверждены автоматическими тестами, но не отдельным ручным прогоном.
