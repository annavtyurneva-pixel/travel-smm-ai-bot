# Подключение Telegram (выполняется после готовности мок-режима)

1. Откройте официальный бот `@BotFather`, выполните `/newbot` и сохраните токен только в локальный `.env` как `TELEGRAM_BOT_TOKEN`.
2. Узнайте свой числовой Telegram ID через доверенный ID-бот или Telegram API и внесите его как `ADMIN_TELEGRAM_ID`.
3. Создайте тестовый канал, добавьте нового бота администратором с правом публикации.
4. Укажите ID канала (обычно начинается с `-100`) как `TARGET_CHANNEL_ID`.
5. Не отправляйте токен или API-ключи в чат и не добавляйте `.env` в Git.
